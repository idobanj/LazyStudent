# LectureJot — Modern Academic Voice Recorder & Live AI Notes

Built with **React 18**, **Vite**, **Tailwind CSS**, and adhering to the **Academic Modernism** and **Academic Modernism Dark** design specifications.

## 🎓 Design System & Features

- **Academic Modernism Palette**: Velvet Burgundy (`#5b021c`, `#7a1c30`), Rose tinted canvases, plus the low-fatigue Obsidian Dark Mode (`#0e0e11`, `#ff4d6d`).
- **Typography**: Newsreader variable serifs paired with Plus Jakarta Sans and Geist ergonomics.
- **Home Voice Recorder & Notes Dashboard**:
  - Daily lecture context bar with timetable integration and quota tracking (18.4 hrs remaining).
  - Tactile Record Hero Button with animated pulsing ring echoes.
  - Quick Academic Stats (Lectures Jot: 42, Flashcards: 184, Transcription accuracy: 98%).
  - Recent Notes cards with dynamic category filtering, bookmark toggles, AI summary snippet, and interactive audio waveform players.
  - Flashcard Quick Review Banner for Spaced Repetition exam prep.
- **Live Active Recording Session**:
  - Pinging REC badge and dynamic seconds/hours counter.
  - Low-glare "Dim Hall" mode for auditorium environments.
  - Real-time frequency waveform audio visualizer.
  - Live Speech Stream with auto-scrolling transcription feed and active spoken highlight cursor.
  - Real-time Structured Academic Jots (Key Concept Definitions, Urgent Deadlines & Announcements, Core Tenets).
  - Multi-language translation switcher (EN Original, Hausa, French, Spanish, Yoruba).
  - Personal note annotation entry during live lectures.
  - Floating Dock controls (Pause / Resume, Stop & Save with celebratory animation, Highlight mark counter with +1 badge).
- **Study & Review Hub**:
  - Interactive flip flashcards for exam review with score tracking and confetti completion.
  - Note Detail Modal with audio scrubber, playback speed toggle (1x, 1.25x, 1.5x, 2x), synchronized transcripts, and markdown/PDF export.
  - Global Search across all lectures, transcripts, and concepts.
  - Schedule Modal with course halls and quick lecture recording launcher.
  - Settings Modal for audio capture quality, hall noise cancellation calibration, and theme toggling.

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start development server
```bash
npm run dev
```

The application will be running at `http://localhost:5173`.

### 3. Build for production
```bash
npm run build
```

The compiled output will be available in the `dist/` directory.
